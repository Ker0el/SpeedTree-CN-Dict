## 这是什么

一份 **`英文界面文本 = 中文译文`** 的对照表，用来把 SpeedTree Modeler 的界面换成中文。

它只是一个词条库，不含可执行文件、不含 DLL、不含 SpeedTree 的任何资源或代码。

| | |
|---|---|
| **适用版本** | SpeedTree Modeler **10.2.0** (Win64 / Qt6) |
| **条目数** | 3265 条有效映射（3109 个唯一键） |
| **文件** | [`translations.txt`](translations.txt) · UTF-8 · 134 KB |
| **覆盖面** | 菜单、属性面板、下拉项、提示气泡、对话框、状态栏 |

## 文件格式

一行一条 `英文=中文`：

```text
File=文件
&File=文件(&F)
Standard	Ctrl+1=标准	Ctrl+1
```

解析规则（与运行时实现一致，`tools/check_dict.py` 也按这个来）：

| 规则 | 说明 |
|---|---|
| 注释 | 以 `#` 开头的整行跳过 |
| 分隔符 | 取**第一个**不属于「空格 = 空格」形式的 `=` |
| 键 | 区分大小写，**精确全文匹配** |
| 值 | 首尾空白会被裁掉 |
| 重复键 | **后出现的覆盖前面的** |
| `&` | Qt 的助记符前缀，`文件(&F)` 会渲染成带下划线的 `文件(F)` |
| `\t` | 制表符分隔标签与快捷键。含 `\t` 时**只翻标签**，快捷键后缀原样保留 |

> 分隔符那条规则不是多余的：英文原文里本身就有 `Drag = brush`、`0.0 = bottom`
> 这种写法，无脑 `Split('=')` 会把它切坏。

## 怎么用

词条本身是纯数据，要配合配套的汉化工具才能生效 —— 工具读取它，
把界面文本换成中文。

想自己接的话：按上面的[解析规则](#文件格式)把 `translations.txt` 读进一张哈希表，
在文本绘制前做精确匹配替换。**测量和绘制要一并处理**，
否则中文变宽会把控件挤到截断。

想改译文：直接改 `translations.txt`，重启程序生效（不用重新编译）。

## 术语约定

这份词典里有一些**刻意统一过**的译法，改动前建议先看一眼：

| 英文 | 中文 | 说明 |
|---|---|---|
| `Frond` / `Fronds` | 叶簇 / 叶状体 | 毛发状的叶片生成器，不是「蕨类」 |
| `Spine` | 骨架线 | 枝条中心线，**不是**骨骼、也不是树干 |
| `Variance` | 变化量 | 指属性的随机变化范围（基准 10、变化 3 → 7–13），不是统计方差 |
| `Knockout` | 剔除 | 与 `Cutout`（沿图像轮廓生成的裁切网格）不是一回事 |
| `Cutout` | 裁切 | 见上 |
| `Level` | 级别 | 枝条层级；`Level 1` = 第 1 级 |
| `Offset` | 偏移 | |
| `Inherited` | 继承 | |
| `Branch Motion` | 树枝运动 | VFX 风效分组 |

**成组枚举保持对称**：`Lit`/`Unlit`、`Enabled`/`Disabled`、`Show`/`Hide` 这类
组内译法必须能对上（`受光`/`不受光` ✅，`受光`/`未点亮` ❌）。

## 已知限制

- **不翻译会被程序读回去当数据用的文本**。例如导出格式下拉的选项会被当作
  文件扩展名用、通道下拉的选项文字会被拼进着色器关键字。
  这类条目在词典里被刻意保留英文。
- **不翻译脚本内容**。代码编辑器里的 Python 源码（`set_property_value(...)`、
  `rule(...)`）翻了会让界面和实际执行不一致。
- 动态拼接的长句、自绘文本、系统公共对话框内的文字可能漏翻。
- 226 条已知待修订项尚未落地（分布在术语统一、漏译、技术文本损坏等类别）。

## 贡献

欢迎提 PR 补词条或修译文。提交前请先跑一遍格式校验：

```bash
python tools/check_dict.py translations.txt
```

它会按运行时的解析规则检查格式、报告重复键与译文冲突。
退出码：`0` 全净 · `1` 有错误 · `2` 仅有警告（例如上面那 26 个已知的译文冲突）。

几条约定：

1. **只改值，别动键**，尤其是键里的大小写、`&`、`\t` 和首尾空格。
2. 拿不准的领域词**先查官方文档**再定，不要凭字面直译。
3. 一个英文键在不同界面含义不同时，请在 PR 里说明**是哪个界面**，不要挑一个译法覆盖所有场景。
4. 专有名词（API 名、着色器表达式、文件筛选模式）保持原样。
